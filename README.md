## 二、入门与命令行（最推荐先看）

| 资源 | 仓库 / 地址 | 说明 |
|---|---|---|
| **The Linux Command Line (TLCL)** | https://linuxcommand.org/tlcl.php | 入门神书，官网可免费下载 PDF，有中译本，讲清命令行如何真正掌控计算机 |
| **101 Linux Commands eBook** | https://github.com/bobbyiliev/101-linux-commands-ebook | 开源电子书，101 个必备 Linux 命令，配套练习 |
| **Linux Basics Course** | https://github.com/kodekloudhub/linux-basics-course | Kodekloud 出品的结构化课程，覆盖 shell 与 shell 脚本 |
| **Linux Journey** | https://linuxjourney.com/ （源码 https://github.com/codingforentrepreneurs/Linux-Journey ） | 交互式免费教程，边学边练，新手友好 |
| **LinuxCommandLine 速查** | https://github.com/danielmapar/LinuxCommandLine | 基础命令合集 + 文件系统层级说明 |

## 四、内核原理（进阶核心）

| 资源 | 仓库 / 地址 | 说明 |
|---|---|---|
| **torvalds/linux（内核源码）** | https://github.com/torvalds/linux | Linus 官方镜像，查看各版本源码与 Tags |
| **Linux Insides** | https://github.com/0xax/linux-insides | 免费在线书，逐行拆解内核启动、内存、中断、调度等机制，基于真实 C/汇编源码 |
| **linux_kernel_wiki（中文）** | https://github.com/0voice/linux_kernel_wiki | 中文内核学习 Wiki，体系化整理 |
| **LKMPG（内核模块编程指南）** | https://github.com/orkan/lkmpg （官方 https://lwn.net/Kernel/LDD3/ ） | Linux 内核模块编程入门指南 |
| **Linux Device Drivers 3rd (LDD3)** | https://lwn.net/Kernel/LDD3/ | 设备驱动开发奠基之作，官方免费在线 |

> 书籍补充：《Understanding the Linux Kernel》《Linux Kernel Development》（Robert Love）——内核原理必读。
